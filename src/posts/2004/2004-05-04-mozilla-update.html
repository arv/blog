It seems Firefox will get its own Windows Mozilla Update. Ben Goodger has put some design documents on his personal web server and I must say that it looks very promising.

I just hope that they got som good designers on this. Although I think mozilla.org looks good I think that the update sites should blend in more with the Firefox UI. I think the layout should have the look and feel like the installer, extension manager and options combined. This is one thing I like about Windows Update, it actually feels like an extension to Windows, not like a random web page out there (like extensionroom.mozdev.org). Looking at the design documents I’m afraid that the Mozilla Update site might not make it to Firefox 0.9 but as long as it is complete for for 1.0 I’m a happy camper.

It would also be interesting to see som usage of XUL here although I understand if mozilla.org wants to stay with HTML to allow access to non Gecko browsers.
