We decided that we wanted to keep the updates coming and therefore I present Bindows 0.91 to you. New in this release is a color picker which is pretty sweet. It uses the HSL color space to allow the user to pick a color from a palette (much like Photoshop). I make the hue-saturation palette image semi transparent to achieve the brightness effect on it (this reminds me I should really add opacity as a property of BiComponent instead of using setStyleProperty).

Another really important update is that the crashes seen in Internet Explorer 6.0.2600.xxxx have been fixed. Still I wonder who dares run that version of IE with all the security patches released since then.
